# Factory Documentation

This is the documentation map for Factory, an open process for building and improving feedback loops around software work.

---

## Documentation Sections

### [Concepts](./concepts/)
Short definitions of Factory vocabulary. These are the building blocks for understanding the process.

Start with [Factory](./concepts/factory.md) to understand the core loop and relationships.

### [Doctrine](./doctrine/)
Durable policy extracted from repeated work. Doctrine is evidence-backed guidance—not motivational prose or untested principles.

This section is growing as patterns are validated across multiple projects.

### [Playbooks](./playbooks/)
Step-by-step procedures for running Factory loops. Playbooks turn concepts and doctrine into actionable sequences.

### [Templates](./templates/)
Copy-and-fill artifacts for common Factory tasks. Templates save time and ensure consistency.

### [Evaluation](./evaluation/)
**The first complete Factory module.** Project Fitness Review framework for evaluating whether a software project can evolve safely under real-world conditions.

Includes the review framework, reviewer checklist, template, scorecard, and example reviews.

## How to Navigate

1. **New to Factory?** Start with [concepts/factory.md](./concepts/factory.md) to understand what Factory is and how its pieces fit together.

2. **Want to evaluate a project?** Jump to [evaluation/README.md](./evaluation/README.md) and follow the recommended reading order.

3. **Looking for reusable templates?** See [templates/README.md](./templates/README.md).

4. **Curious about current doctrine?** Browse [doctrine/README.md](./doctrine/README.md) (growing section).
