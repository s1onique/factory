# Concepts

Short definitions of Factory vocabulary. Concepts are the building blocks for understanding the process.

## Purpose

Concepts provide clear, reusable definitions for terms used across Factory documentation. They help ensure consistent language and reduce ambiguity.

## What belongs here

- Core vocabulary definitions (short, precise)
- Relationship explanations between terms
- Boundary clarifications (what something is vs. is not)
